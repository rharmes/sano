Color & theme

Every color is a CSS custom property declared on html in css/sano.css, with a dark override inside @media (prefers-color-scheme: dark). There is no theme toggle — the OS decides. Always edit both blocks together. Chips below are rendered with the live token, so they already reflect your current mode; both hex values are listed for reference.

Typography

Two self-hosted families (no external requests). Neuton (serif, 700 only) is the display voice — the wordmark, headings, and every Nepali phrase. Lato (300 / 400 / 700, plus 300 / 400 italic) carries all UI and body copy; italic Lato is the house style for Romanized pronunciations. Sizes are rem on a 62.5% base, so 1rem = 10px (body 2.3rem = 23px).

Iconography

Icons are an inline SVG sprite of Material Icons symbols (#i-*) defined once in index.html, used via <use href="#i-name">. Wrap each in <span class="icon"> (or a chromeless <button class="icon"> for actions): the wrapper's font-size sets glyph size and color sets fill (currentColor). No icon font, no network request.

Sano the mascot

A paper-cut mouse built from layered SVG polygons on a viewBox="30 10 160 174" (widened from the original to give the tilted ears headroom). Fills are theme tokens via .f-indigo / .f-crimson / .f-petal / .f-cream / .f-cream-deep / .f-ink and the .s-whisker stroke. The indigo backing is split into separate head and body outlines so the head can tilt independently, and the moving parts live in named groups (.sano-head / .sano-tail / .sano-eyes / .sano-ear / .sano-nose) that the idle loops target. The footer uses a head-only crop — which carries a bolder indigo outline (tapered at the bottom to follow the chin) plus the full mascot's whiskers. Sano renders flat: shapes are layered directly with no drop-shadow or grain.

Buttons & inputs

The base layer is barebones.css (38px controls, --accent mapped from crimson). Sano's own primary buttons override that to a softer, rounder shape: 1rem radius, mixed-case 700 Lato, crimson fill that deepens on hover. Indigo is the "advance / complete" variant. Icon buttons drop all chrome and tint with currentColor.

Panels & cards

Floating surfaces (the login panel, popovers) use the page background, a --border-color hairline, 1rem radius, and a soft drop-shadow. Inset rows are divided with --border-color-softer.

Motion

Animation is gentle and purposeful: staggered top-to-bottom reveals on the lesson path, a pop-in + head-wobble + tail-wag flourish on lesson completion, and a set of slow, periodic idle motions that keep Sano feeling alive without distracting (most of each cycle is at rest; periods are de-synced so motions don't all fire at once). Wherever Sano appears it runs these idle loops — the full mascot does all five (tail wag, head tilt, eye blink, ear wiggle, nose wiggle); the footer head crop runs only the three that read at thumbnail size (blink, ear, nose). Every Sano on this page is idling right now.

  • Always honor prefers-reduced-motion: reduce — every animated rule needs an opt-out (see the block at the bottom of css/sano.css).
  • Idle loops are long and quiet. 4–22s periods with a short active window read as "alive," not "busy."
  • Celebrate completion, not every tap. The big motion budget is spent on the lesson-complete screen.

Design decisions

  • Brand: “Pennant & Paper-cut.” Softened Nepal-flag crimson + indigo on warm paper stock, with a paper-cut mouse named Sano and a Nepal-pennant favicon/app icon.
  • Tokens are the contract. All theme values live as CSS variables at the top of css/sano.css — a light block and a dark @media block. Change both; never hard-code a hex in a component.
  • Dark mode is automatic. Driven entirely by prefers-color-scheme; dark is midnight card stock with colors lifted one step for contrast. No manual toggle.
  • No build step, no runtime network. Plain HTML/CSS/JS. Fonts are self-hosted woff2 (Neuton, Lato); icons are an inline SVG sprite. The only fetches are same-origin calls to api/.
  • 1rem = 10px. Base font-size is 62.5% — read every rem as "tenths of the value × 10px."
  • Buttons round, not boxy. Primary actions are 1rem-radius crimson with mixed-case 700 Lato — softer than the barebones default they override.
  • Two type voices. Neuton 700 for display + all Nepali; Lato for everything else, italic for Romanized pronunciation.
  • Design files live in design/. Committed but excluded from the deploy rsync — nothing here ships to the live site. This guide and the animation tuner both live here.
